# Built in the open

KMP-Vision is maintained by [lamplis](https://github.com/lamplis). The goal is to make mobile vision capabilities easier to share across Android and iOS, with understandable APIs and examples developers can run and adapt.

## Contribute something useful

- **Try the tutorial.** Report the platform, OS version, and steps when something fails.
- **Improve the guides.** Clear examples and accurate platform notes help the next developer get started.
- **Share a focused fix.** Include a reproducible case and describe how you validated it on the affected platforms.
- **Discuss a feature.** Explain the use case and proposed shared API before investing in a large change.

[Open an issue](https://github.com/lamplis/kmp-vision/issues) · [Browse the source](https://github.com/lamplis/kmp-vision) · [Meet the maintainer](https://github.com/lamplis)

## Project origins

The camera and image-picker foundations come from [Peekaboo](https://github.com/onseok/peekaboo), created by onseok and contributors. Existing copyright notices are retained in the source.

The OCR approach draws inspiration from [Compose Multiplatform Text Recognition](https://github.com/Amirhosseinijadi/ComposeMultiplatformTextRecognition) by Amirhossein Ijadi; that repository is not copied into this project.

KMP-Vision extends these foundations with shared OCR, overlays, frame-analysis integration, and model-inference APIs. Giving credit is part of building useful open source.
